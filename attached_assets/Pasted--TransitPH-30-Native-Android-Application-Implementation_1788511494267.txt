# TransitPH – 30% Native Android Application Implementation

Build a functional **native Android mobile application called TransitPH**, an integrated multi-modal transit navigation and commuter safety system focused specifically on **CALABARZON, Philippines**.

This is a **30% implementation/prototype** of the proposed TransitPH system. Prioritize the core functionality and make the implemented features actually functional.

---

# IMPORTANT TECHNOLOGY REQUIREMENT

The application MUST be developed as a **native Android Studio application**.

Use:

* **Java** for all application logic
* **XML** for all user interfaces/layouts
* **Android Studio** as the development environment
* **Gradle** for project/build configuration
* **SQLite / Room Database** for local database storage
* Android Activities and/or Fragments for navigation

DO NOT use:

* Kotlin
* Jetpack Compose
* Flutter
* React Native
* React
* HTML/CSS/JavaScript for the application UI
* Ionic
* .NET MAUI

The final project must be a standard Android Studio project that can be opened and run in Android Studio.

---

# 1. APPLICATION PURPOSE

TransitPH helps commuters plan trips around **CALABARZON** by providing information about:

* Jeepney terminals
* Jeepney routes
* Destinations
* Walking directions
* Basic fare information
* Location-specific weather

The PRIMARY feature for this 30% implementation is the:

## Jeepney Terminal Tracker + Route Finder

When a user searches for a destination, the application should show:

1. Relevant jeepney terminal
2. Jeepney routes available from that terminal
3. Destinations served by each route
4. Estimated fare
5. Estimated travel time
6. Basic walking instructions

The proposed TransitPH solution specifically focuses on jeepney terminals, routes, destinations, and weather functionality.
